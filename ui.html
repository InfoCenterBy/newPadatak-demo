Библиотека компонентов

Справочник UI-компонентов проекта. Включает кастомные компоненты и компоненты из DaisyUI v5.

Шапка

Верхняя часть сайта. Включает логотип, строку поиска, контактный телефон и кнопки авторизации. На мобильных устройствах отображается упрощенная версия с гамбургер-меню.

Компонент не принимает пропсов и является самодостаточным: управляет состоянием мобильного меню внутри через useRef. Используется в MainLayout. Отображается вверху данной страницы.

import Header from '../components/system/Header'

<Header />

Узкая полоса с актуальными данными НБРБ: курсы USD, EUR, RUB, ставка рефинансирования, базовая величина и МЗП. Данные загружаются при монтировании; пока идет загрузка, вместо чисел отображаются скелетоны.

Навигационная цепочка. Первый элемент всегда иконка домика (главная страница). Последний элемент недоступен для клика и выделен серым цветом.

const breadcrumbs: BreadcrumbItem[] = [
  { title: 'Раздел', url: '/section' },
  { title: 'Текущая страница', url: '#' },

<BreadCrumbs breadcrumbs={breadcrumbs} />

Компонент обернут в <Container>. В MainLayout передается через проп breadcrumbs.

import EmblaCarousel from '../components/main/slider/emblaCarousel'

// Вариант с заголовком и кнопками вверху справа
<EmblaCarousel
  arrowPosition="top-right"
  carouselTitle="Название раздела"
  carouselLinkText="Смотреть все"
  carouselLinkHref="/section"
  options={{ loop: false }}
  dots={false}
>
  <div className="slider-slide">...</div>
</EmblaCarousel>

// Вариант с кнопками по бокам
<EmblaCarousel arrowPosition="inline" options={{ loop: true }}>
  <div className="slider-slide">...</div>
</EmblaCarousel>

Каждый дочерний элемент должен иметь класс slider-slide. Проп options принимает EmblaOptionsType из пакета embla-carousel.

Пагинация

Постраничная навигация. Автоматически формирует диапазон с многоточиями. При 6 и менее страницах показывает все номера без сокращений.

123...101112

мало страниц

12345
import Pagination from '../components/system/Pagination'

<Pagination
  totalPages={20}
  currentPage={5}
  getPageHref={(page) => `/news?page=${page}`}
  ariaLabel="Навигация по новостям"
/>

getPageHref возвращает URL для конкретного номера страницы. Компонент использует теги <a>, что обеспечивает работу без JavaScript.

Модальное окно

Диалоговое окно поверх основного контента. Основано на нативном HTML-элементе dialog. Закрывается кликом на затемненный фон или кнопкой внутри.

Заголовок диалога

Содержимое модального окна. Нажмите кнопку или кликните на фон для закрытия.

import { useRef } from 'react'

const modalRef = useRef<HTMLDialogElement>(null)

// Открыть:
modalRef.current?.showModal()

<dialog ref={modalRef} className="modal">
  <div className="modal-box">
    <h3 className="font-bold text-lg">Заголовок</h3>
    <p className="py-4">Содержимое</p>
    <div className="modal-action">
      <form method="dialog">
        <button className="btn">Закрыть</button>
      </form>
    </div>
  </div>
  <form method="dialog" className="modal-backdrop">
    <button>Закрыть</button>
  </form>
</dialog>

Радио

Переключатель между несколькими взаимоисключающими вариантами. Объединяются атрибутом name.

<label className="flex items-center gap-2 cursor-pointer">
  <input type="radio" name="group" className="radio radio-primary" />
  <span>Вариант</span>
</label>

Переключатель

Элемент для включения и выключения опции.

<label className="flex items-center gap-2 cursor-pointer">
  <input type="checkbox" className="toggle toggle-primary" />
  <span>Включить функцию</span>
</label>

Прогресс

Полоса прогресса выполнения задачи. Без атрибута value отображает анимацию ожидания.

// С заданным значением
<progress className="w-full progress progress-primary" value={60} max={100} />

// Неопределённый (анимация ожидания)
<progress className="w-full progress progress-primary" />

Тултип

Всплывающая подсказка при наведении на элемент. Текст задается через атрибут data-tip.

<div className="tooltip" data-tip="Текст подсказки">
  <button className="btn">Наведите курсор</button>
</div>

// Позиция: tooltip-right, tooltip-bottom, tooltip-left

Аккордеон

Раскрывающиеся секции контента. С radio одновременно открыта только одна; с checkbox секции независимы.

Первый пункт
Содержимое секции. Может включать произвольный контент.
Второй пункт
Содержимое секции. Может включать произвольный контент.
Третий пункт
Содержимое секции. Может включать произвольный контент.
// Группа (radio) — одновременно открыта только одна
<div className="collapse collapse-arrow border border-base-300 rounded-box">
  <input type="radio" name="accordion" defaultChecked />
  <div className="collapse-title font-medium">Заголовок</div>
  <div className="collapse-content">Содержимое</div>
</div>

// Независимый (checkbox)
<div className="collapse collapse-arrow border border-base-300 rounded-box">
  <input type="checkbox" />
  <div className="collapse-title font-medium">Заголовок</div>
  <div className="collapse-content">Содержимое</div>
</div>
